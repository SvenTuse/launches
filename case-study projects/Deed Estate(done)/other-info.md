## 1. Token identity and launch — primary transaction evidence

[Robinscan’s creation transaction](https://robinscan.io/tx/0x36536d4e8bd99303b7782e88dfe965f2cd9be5e8169725400eb2b4e884f94bc7) records deployment at **2026-09-21 23:51:56 UTC**, block **69,205,683**, with **1,000,000,000 DEED** minted to the market and **29,900,000** transferred to the initiating wallet, **0x0052BB21e9cccfcb790913fe3d9bc52cc45d9dD9**. Its `launchAndBuy` input includes an array of **25 snipe-tax-exemption addresses**, and metadata points to **x.com/deedestate, t.me/deedestate and deed.estate**. This confirms the target token and launch parameters, not common wallet ownership, later insider sales or real-estate backing.

The [token page](https://robinscan.io/address/0x5e55f18453545d0d4314c5106a2d8db934298e95) identifies DEED and the same creator. Robinscan explicitly says it is not affiliated with Robinhood Markets. The linked Blockscout token page yielded no usable text, so no vault ABI or property attestation was verified.
